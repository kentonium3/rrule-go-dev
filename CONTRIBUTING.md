# Contributing

Thanks for your interest. This repository is a development workspace and does not
take contributions directly.

Please open issues, questions and pull requests on the library repository,
[kentonium3/rrule-go](https://github.com/kentonium3/rrule-go), and follow its
[contributing guide](https://github.com/kentonium3/rrule-go/blob/main/CONTRIBUTING.md).
Report security problems privately through its
[security advisories](https://github.com/kentonium3/rrule-go/security/advisories/new).

Pull requests opened here will be closed with a pointer to the library repository.
