# Security policy

Report security problems in rrule-go (for example a panic, hang or runaway CPU or
memory use on a rule the parser accepts) privately through the library repository's
[security advisories](https://github.com/kentonium3/rrule-go/security/advisories/new).
See its [security policy](https://github.com/kentonium3/rrule-go/blob/main/SECURITY.md)
for what to include. Please do not report them in this repository.
